# 💰 Семейный бюджет

Личное приложение для учёта семейных финансов. Работает в браузере телефона, ставится на главный экран как обычное приложение, работает без интернета. Данные синхронизируются между телефонами через **приватный** репозиторий GitHub.

**Что умеет:** доходы, расходы и переводы между счетами · бюджет по категориям с индикатором перерасхода · счета и их остатки · долги и кредиты · регулярные платежи с отметкой «оплачено» · финансовые цели с расчётом даты достижения · аналитика (куда уходят деньги, 12 месяцев, кто сколько тратит) · PIN-код · экспорт в CSV/Excel и JSON.

---

## Как это устроено (и почему приватно)

| Что | Где лежит | Кто видит |
|---|---|---|
| Код приложения (этот репозиторий) | GitHub Pages | Код может быть публичным: **в нём нет ваших данных** |
| Ваши данные (`data.json`) | Отдельный **приватный** репозиторий | Только вы (и те, кому дадите токен) |
| Токен доступа | Только в памяти телефона | Только этот телефон |

> Если у вас GitHub Pro, можно сделать приватным и сам репозиторий с кодом. На бесплатном аккаунте GitHub Pages работает только для публичных репозиториев — поэтому данные вынесены отдельно.

## Установка (≈10 минут, один раз)

### 1. Репозиторий с приложением
1. На github.com → **New repository** → имя, например `budget` → **Public** → Create.
2. **Add file → Upload files** → перетащите все файлы из этой папки (`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты приложение будет по адресу `https://ВАШ_ЛОГИН.github.io/budget/`.

### 2. Приватный репозиторий для данных
1. **New repository** → имя `family-budget-data` → **Private** → поставьте галочку **Add a README file** → Create.
   (Файл `data.json` приложение создаст само.)

### 3. Токен доступа (только к репозиторию данных)
1. github.com → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Token name: `budget-phone`; Expiration: на ваш выбор (например, 1 год).
3. **Repository access → Only select repositories →** `family-budget-data`.
4. **Permissions → Repository permissions → Contents → Read and write**. Больше ничего не нужно.
5. **Generate token** → скопируйте (`github_pat_...`).

> Токен даёт доступ только к одному репозиторию с данными — даже если телефон потеряется, остальной GitHub в безопасности. Отозвать токен можно в том же разделе.

### 4. Подключить телефон
1. Откройте `https://ВАШ_ЛОГИН.github.io/budget/` на телефоне.
2. **Ещё → Настройки и синхронизация** → введите логин, `family-budget-data`, токен → **Сохранить и синхронизировать**. Индикатор вверху станет зелёным.
3. Поставьте на главный экран:
   - **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
   - **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
4. По желанию: **Настройки → PIN-код**.

### 5. Телефон жены
Повторите шаг 4 с теми же настройками (можно сделать ей отдельный токен по шагу 3 — тогда его можно отозвать независимо). Бюджет станет общим; в каждой операции отмечается, кто потратил.

## Как пользоваться

- **«+»** — новая операция. Сумму можно вводить выражением: `120+45+38`.
- **Перевод** — снять наличные с карты, пополнить другую карту (не считается расходом).
- **Бюджет** — нажмите на категорию, чтобы задать лимит. Кнопка «Скопировать из прошлого месяца» переносит лимиты.
- **Ещё → Регулярные платежи** — аренда, коммуналка, подписки. На главной видно, что ещё не оплачено; «Оплачено» сразу создаёт расход.
- **Ещё → Цели** — укажите сумму и сколько откладываете в месяц, приложение покажет дату достижения.
- **Ещё → Счета** — укажите начальный остаток каждой карты/наличных на день начала учёта.

## Синхронизация и конфликты
- Изменения отправляются через пару секунд после сохранения и при сворачивании приложения. Без интернета всё сохраняется в телефоне и отправится позже (жёлтая точка).
- Если вы с женой одновременно добавили операции на разных телефонах — объединятся обе. При правке одной и той же записи побеждает более поздняя правка.
- Каждое сохранение — коммит в `family-budget-data`, поэтому вся история изменений сохраняется и любую версию можно восстановить.

## Резервная копия
**Настройки → Скачать JSON** (полная копия) или **CSV** (открывается в Excel / Google Таблицах). «Загрузить JSON» добавляет данные из файла к текущим.

## Обновление приложения
Замените `index.html` в репозитории новым — телефон подхватит при следующем открытии с интернетом. Данные при этом не трогаются.
