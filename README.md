# 💰 Сімейний бюджет

Особистий застосунок для обліку сімейних фінансів. Працює в браузері телефона, встановлюється на головний екран як звичайний застосунок, працює без інтернету. Дані синхронізуються між телефонами через **приватний** репозиторій GitHub.

**Що вміє:** доходи, витрати й перекази між рахунками · бюджет за категоріями з індикатором перевитрати · рахунки та їхні залишки · борги й кредити · регулярні платежі з позначкою «сплачено» · фінансові цілі з розрахунком дати досягнення · аналітика (куди йдуть гроші, 12 місяців, хто скільки витрачає) · PIN-код · експорт у CSV/Excel і JSON.

---

## Як це влаштовано (і чому приватно)

| Що | Де лежить | Хто бачить |
|---|---|---|
| Код застосунку (цей репозиторій) | GitHub Pages | Код може бути публічним: **у ньому немає ваших даних** |
| Ваші дані (`data.json`) | Окремий **приватний** репозиторій | Лише ви (і ті, кому дасте токен) |
| Токен доступу | Лише в памʼяті телефона | Лише цей телефон |

> Якщо у вас GitHub Pro, можна зробити приватним і сам репозиторій із кодом. На безкоштовному акаунті GitHub Pages працює лише для публічних репозиторіїв — тому дані винесено окремо.

---

## Встановлення (≈10 хвилин, один раз)

### 1. Репозиторій із застосунком
1. На github.com → **New repository** → назва, наприклад `budget` → **Public** → Create.
2. **uploading an existing file** → перетягніть усі файли з цієї папки (`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–3 хвилини застосунок буде за адресою `https://ВАШ_ЛОГІН.github.io/budget/`.

### 2. Приватний репозиторій для даних
1. **New repository** → назва `family-budget-data` → **Private** → увімкніть **Add README** → Create.
   (Файл `data.json` застосунок створить сам.)

### 3. Токен доступу (лише до репозиторію даних)
1. github.com → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Token name: `budget-phone`; Expiration: на ваш вибір (наприклад, 1 рік).
3. **Repository access → Only select repositories →** `family-budget-data`.
4. **Permissions → Repository permissions → Contents → Read and write**. Більше нічого не потрібно.
5. **Generate token** → скопіюйте (`github_pat_...`). Він показується лише один раз.

> Токен дає доступ лише до одного репозиторію з даними — навіть якщо телефон загубиться, решта GitHub у безпеці. Відкликати токен можна в тому ж розділі.

### 4. Підключити телефон
1. Відкрийте `https://ВАШ_ЛОГІН.github.io/budget/` на телефоні.
2. **Ще → Налаштування й синхронізація** → введіть логін, `family-budget-data`, токен → **Зберегти й синхронізувати**. Індикатор угорі стане зеленим.
3. Додайте на головний екран:
   - **iPhone (Safari):** «Поділитися» → «На екран „Додому“».
   - **Android (Chrome):** меню ⋮ → «Додати на головний екран» / «Встановити застосунок».
4. За бажанням: **Налаштування → PIN-код**.

### 5. Телефон дружини
Повторіть крок 4 з тими самими налаштуваннями (можна зробити їй окремий токен за кроком 3 — тоді його можна відкликати незалежно). Бюджет стане спільним; у кожній операції позначається, хто витратив.

## Як користуватися

- **«+»** — нова операція. Суму можна вводити виразом: `120+45+38`.
- **Переказ** — зняти готівку з картки, поповнити іншу картку (не рахується витратою).
- **Бюджет** — натисніть на категорію, щоб задати ліміт. Кнопка «Скопіювати ліміти з минулого місяця» переносить ліміти.
- **Ще → Регулярні платежі** — оренда, комуналка, підписки. На головній видно, що ще не сплачено; «Сплачено» одразу створює витрату.
- **Ще → Фінансові цілі** — вкажіть суму і скільки відкладаєте на місяць, застосунок покаже дату досягнення.
- **Ще → Рахунки** — вкажіть початковий залишок кожної картки/готівки на день початку обліку.

## Синхронізація та конфлікти
- Зміни надсилаються через кілька секунд після збереження і при згортанні застосунку. Без інтернету все зберігається в телефоні й надішлеться пізніше (жовта крапка).
- Якщо ви з дружиною одночасно додали операції на різних телефонах — обʼєднаються обидві. Якщо редагували той самий запис — перемагає пізніша правка.
- Кожне збереження — коміт у `family-budget-data`, тож уся історія змін зберігається і будь-яку версію можна відновити.

## Резервна копія
**Налаштування → Завантажити JSON** (повна копія) або **CSV** (відкривається в Excel / Google Таблицях). «Імпортувати JSON» додає дані з файлу до поточних.

## Оновлення застосунку
Замініть `index.html` у репозиторії новим — телефон підхопить при наступному відкритті з інтернетом. Дані при цьому не змінюються.
